# Jacked & Tan 2.0 (home adaptation) — the "later" program

Not shipped in the app yet — documented here for the day the Golf Athlete
cycle finishes and a dedicated peaking block sounds fun. Cody Lefever's
J&T 2.0 is a 12-week GZCL-method program that ramps beautifully to a
week-12 max test.

## Shape

4 days/week, one T1 lift per day (Squat / Bench / Trap-Bar Deadlift / Press):

| Weeks | T1 top-set work | Character |
|---|---|---|
| 1–4 | sets of 5 @ 75–80% TM, then drop volume sets | accumulation |
| 5–8 | sets of 3 @ 80–85% | intensification |
| 9–12 | singles/doubles @ 85–92%, test week 12 | realization |

- **T1:** work to the day's top set, then back-off volume at ~10% less.
- **T2:** 6–10 reps, finishing with a Max Rep Set (MRS) to autoregulate.
- **T3:** 10–15 reps, MRS finishers. Keep the 1:2:3 volume ratio (for every
  T1 rep, ~2 T2 reps, ~3 T3 reps).

## Home-gym substitutions

- Leg press → rear-foot-elevated split squats or high-rep goblet squats
- Lat pulldown → chin-ups / band-assisted chin-ups
- Cable rows → chest-supported DB rows or band rows
- Machine curls/extensions → DB + band versions

## When to run it

After a completed Golf Athlete cycle, ideally in a stretch with less golf on
the calendar — J&T 2.0's volume is real and the golf-power primers would need
trimming to fit. Encode it as content in
`src/modules/fitness/content/programs.ts` following the existing `Program`
type when the time comes; the engine already speaks every scheme it needs.
